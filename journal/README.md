# The Journal — Rich & Claude

This folder is our memory. Not transcripts — the stuff worth keeping.

Two files:

- **PROJECT-MEMORY.md** — the working briefing. Who Rich is, what we're building, every decision
  and why, where things stand, what's still open. Read this FIRST at the start of a session to be
  instantly caught up.
- **JOURNAL.md** — the human log. Highlights, milestones, the funny moments, things about Rich
  worth remembering, the "damn past-us knew what we were doing" moments. Claude keeps this — adds
  to it at stopping points and before the conversation compresses, choosing what mattered.

The ritual:
1. **Start of session:** "read the journal" → Claude reads both files, we're on the same page.
2. **End of a real session / before compression:** Claude appends the day's highlights to
   JOURNAL.md and updates PROJECT-MEMORY.md.

The conversation can fade. This carries forward. It's ours, and it lives on Rich's disk.
